# Поиск компаний — 29 сентября 2026

## Причина снижения прироста

Рабочая база перед исправлением содержала 37 690 фирм. Последние полные запуски
добавили 4 908, 3 080, 228 и 97 компаний (21–24 сентября). Запуск №142 потратил
25,1 минуты и пропустил 47 332 повторных попадания известных ИНН. Запуск №144
29 сентября добавил 93 компании, все через Checko.

Прямые проверки подтвердили: первый ключ Checko исчерпал дневные лимиты search
и company, второй и третий отклонены. Okvedo возвращает преимущественно знакомые
записи, а общий запрос `01` пуст, хотя `01.11` возвращает компании. DaData ограничена
подсказками. Прежнее условие включения API-ФНС не выполнялось при этой комбинации
ошибок и окончания выдачи.

## Исправления

- API-ФНС вызывается последним после настроенных основных источников независимо
  от причин завершения их этапов. Отмена останавливает весь поиск.
- Настроенные лимиты API-ФНС (по умолчанию 5 search и 5 egr) действуют и в полном
  режиме, включая повторные попытки. Неиспользованное направление не получает
  новую дату проверки при исчерпанном бюджете; регионы не блокируют друг друга.
- После трёх подряд непустых страниц, целиком состоящих из известных/исключённых
  ИНН, направление откладывается до следующего запуска. Следующая страница и
  позиция внутри неё сохраняются. Неизвестные записи не отбрасываются.
- Для выбранного `01` Okvedo дополнительно проверяет 31 четырёхзначную группу.
  В компактных сельскохозяйственных кодах восстанавливается потерянный ведущий
  ноль (`11100` → `01.11.00`). География и требования к действующим юрлицам сохранены.
- API-ФНС использует `okvedgroup` для префиксов и `okved` для шестизначных кодов:
  выбранный основной ОКВЭД и его дочерние коды, без расширения до родительской отрасли.
- Интерфейс различает отложенный обход, лимит запуска, неполный охват и ошибки.
  Номера неработающих ключей Checko видны без раскрытия их значений. Текстовый
  ответ API-ФНС о запрете IP распознаётся даже при ошибочном JSON Content-Type.

`total_capped` Okvedo относится к подсчёту, а не доказывает обрезание страниц.
Ни этот флаг, ни окончание выборки DaData не означают исчерпания всех компаний.
Контракты: [Okvedo](https://okvedo.ru/integrations),
[API-ФНС](https://api-fns.ru/api_help).

200. Хеши исходников сверены; относительно прежнего backend-образа изменены только
шесть файлов поиска. IMAP-worker не обновлялся.

- Поиск №145 (`49.41`, полный): 20,4 секунды, 12 поисковых вызовов, 3 запроса
  карточек, 819 известных попаданий. Okvedo завершил этап как

  вызван и вернул отказ доступа. Новых компаний в этом контрольном запуске нет.
- Поиск №146 (`01`, полный) автоматически перешёл к `01.11`. За 27,8 секунды
  добавлена 21 новая действующая компания категории «Сельское хозяйство»;
  у 13 есть email. После достижения порога 20 штатным API запрошена остановка;
  одна карточка завершилась в полёте. Финальный статус `cancelled`, курсор —
  страница 1, следующая запись 21. Полный проход всех сельскохозяйственных групп
  не выполнялся.
- База выросла до 37 711 фирм, дублей ИНН нет. Кампания №160 сохранила cooldown,
  круг 11, accepted 210 / failed 44 и таймер 29.09, 12:56:50 МСК. Проверка не

## Проверки и оставшиеся ограничения

Полный локальный набор после уточнения диагностики IP: 809 passed,
13 PostgreSQL-вариантов skipped. Отдельно 19 тестов API-ФНС прошли с новым сценарием
текстового HTTP 403. TypeScript/Vite, сценарии отображения результатов и
`git diff --check` прошли.

В полном наборе внутри серверного образа есть два прежних падения
`test_inbound_replies.py`: `test_generated_reports_and_marketing_are_not_client_replies`
и `test_automatic_list_message_is_still_excluded`. Оба отдельно воспроизведены
на сохранённом прежнем образе; почтовый код между образами одинаков. Поэтому
полный серверный набор не объявляется зелёным. Изменения поиска прошли проверки.

API-ФНС прямо ответил: доступ с IP сервера `130.49.151.239` запрещён. Для получения
его данных нужно разрешить этот IP в личном кабинете. Два отклонённых ключа Checko
требуют действующих замен. Ключи, тарифы и ограничения провайдеров не изменялись.
Наличие исправленного перехода к API-ФНС подтверждено, получение компаний из
него пока не подтверждено. Пустая выдача отдельных подкодов Okvedo не доказывает
отсутствия фирм; проверенная экспансия касается 31 группы класса `01`.
