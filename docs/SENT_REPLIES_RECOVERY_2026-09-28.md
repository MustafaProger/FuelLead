записи отдельно не установлена.

Восстановлены полные тексты, темы, исходные даты, адреса и заголовки связи.
Вложений у трёх писем нет. События имеют тип `email_sent`, источник
`imap_sent_recovery` и ключ операции `sent-replies-recovery-20260928`.

## Проверка и границы

Авторизованный API подтвердил все три сообщения с исходными датами и полными
текстами: в деталях №53 теперь семь сообщений, у №110 — четыре. Количество
входящих осталось 28, переписок с ответами — 24, непрочитанных — ноль.
Повторная полная сверка 2 142 исходящих: пропущенных связанных сообщений —
ноль, ошибок — ноль. Повторный проверочный запуск восстановления нашёл ровно
по одной существующей записи каждого из трёх писем, новых записей не создал.
Список «Переписка» штатно содержит компании с входящими; восстановленное
исходящее КП само по себе не создаёт входящий ответ и новую строку списка.

Контрольное сравнение подтвердило неизменность количества компаний, статусов
и времени обновления №53/110, кампаний, счётчиков отправителей и IMAP-курсоров.
Рассылка №158 осталась на паузе. SMTP не вызывался, новые письма не отправлялись.
Код приложения не изменялся; автоматический импорт будущих внешних исходящих
этим разовым восстановлением не добавлен. Визуальная проверка не заявляется.
