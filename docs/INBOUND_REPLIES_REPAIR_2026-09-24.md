# Восстановление входящих ответов — 24 сентября 2026

На сервере `130.49.151.239` обновлены backend и imap-worker. Переписка проверена
через авторизованный API и браузер с временным локальным прокси только для чтения.

## Подтверждённая причина

Парсер отбрасывал письма с `Auto-Submitted: auto-generated` до поиска связи
с отправленным предложением. Так были пропущены четыре отписки Mail.ru и три
автоответа сотрудников RBC по предложению для «Профстройки». Ещё два старых
`auto-replied` уже поддерживались парсером, но оставались за IMAP-курсором
после прежней обработки и поэтому не появлялись при обычном обновлении почты.
API и интерфейс не скрывали сохранённые события.

## Изменения

- Автоматические ответы с другими значениями `Auto-Submitted` сохраняются при
  наличии связи с перепиской или фактической отправкой из принимающего ящика.
  Автоответ об отпуске не меняет статус компании.
- Явный автоматически сформированный `unsubscribe` сохраняется как отказ,
  с применением существующей защиты от дальнейших отправок.
- Заголовки списка рассылки больше не отбрасывают письмо с подтверждённой
  ссылкой на переписку. Посторонние рассылки не привязываются по одному адресу.
- Сопоставление учитывает предыдущие входящие Message-ID и адрес получателя
  сохранённой отправки, даже если контакт компании впоследствии изменён.
- Сохраняются ответы с содержимым только в теме.
- Команда `reprocess_replies` получила `--replies-only`, повторяемый
  `--account-id` и сводку `missing/existing/created/errors`. Режим
  `--replies-only` не выполняет общий проход по всем ранее отказавшим компаниям.
